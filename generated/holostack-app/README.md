# Carros Web App

Este projeto é uma aplicação web para visualização de uma lista de carros, construída com React e TypeScript. Utiliza o Vite para o bundling e Tailwind CSS para o styling.

## Scripts Disponíveis

- `npm install`: Instala as dependências do projeto.
- `npm run dev`: Executa a aplicação em modo de desenvolvimento.
- `npm run build`: Cria a build de produção.

## Estrutura do Projeto

- `src/components`: Componentes React utilizados na aplicação.
- `src/services`: Serviços para chamadas de API.
- `src/store`: Estado global gerido com hooks.

## Configurações

- `vite.config.ts`: Configurações do Vite.
- `tailwind.config.ts`: Configurações do Tailwind CSS.
