# Luxury Car Site

Este projeto é um site de carros de luxo desenvolvido com Next.js e Vite. Utiliza Tailwind CSS para o design e oferece uma experiência rica e interativa para os usuários.

## Instalação

1. Clone o repositório.
2. Execute `npm install` para instalar as dependências.
3. Inicie o servidor de desenvolvimento com `npm run dev`.

## Estrutura

- `src/components`: Componentes React reutilizáveis.
- `src/services`: Serviços para chamadas de API e lógica de negócios.
- `src/hooks`: Hooks personalizados para gerenciamento de estado.
