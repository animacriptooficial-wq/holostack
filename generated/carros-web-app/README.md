# Car Showcase

This is a car showcase web application built with React and Vite. It lists various cars and displays detailed information about each one.

## Features

- List of cars
- Detailed view of selected car

## Setup

1. Clone the repository.
2. Install dependencies with `npm install`.
3. Run the development server with `npm run dev`.

## Technologies Used

- React
- Vite
- TypeScript
- Tailwind CSS
